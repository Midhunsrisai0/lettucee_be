# Setup Guide for New Contributors

This project is a Cloudflare Workers backend using Hono + D1 + Drizzle.

If you are new to Cloudflare Workers, read this once and follow the commands exactly.

---

## 1) Tech stack

- Runtime: Cloudflare Workers
- API framework: Hono
- Database: Cloudflare D1 (SQLite)
- ORM / schema tool: Drizzle
- Migrations: SQL files generated by Drizzle and applied via Wrangler

---

## 2) Local vs Remote (important)

There are two database modes:

- **Local D1**: database on your laptop (Wrangler-managed)
- **Remote D1**: database in Cloudflare account

Your code always uses `c.env.DB`.

The command decides local vs remote:

- Local examples: `wrangler dev`, `... --local`
- Remote examples: `wrangler dev --remote`, `... --remote`, deployed Worker

---

## 3) First-time setup (contributor, no Cloudflare access needed)

1. Install dependencies

```bash
npm install
```

2. Apply local migrations

```bash
npm run db:migrate:local
```

3. Start local dev server

```bash
npm run dev
```

That is enough for normal feature development.

---

## 4) Useful local DB commands

```bash
# list tables
npm run db:tables:local

# list users
npm run db:users:local

# run custom SQL on local DB
npm run db:query:local -- "SELECT * FROM users LIMIT 20;"
```

---

## 5) Schema change workflow (Drizzle)

When you change DB schema:

1. Edit schema in `src/db/schema.ts`
2. Generate migration SQL

```bash
npm run db:generate
```

3. Apply migration locally

```bash
npm run db:migrate:local
```

4. Test app
5. Commit both:
   - schema changes
   - generated migration files in `migrations/`

Do **not** edit old applied migration files.

---

## 6) Team workflow and permissions

Most contributors should use **local only**:

- `npm run dev`
- `db:migrate:local`

They should not run remote deploy/migration unless they have Cloudflare access.

If someone runs `npm run dev -- --remote` without access, it will fail.

---

## 7) Deployment model

Deploy target is Cloudflare Workers (no container image needed).

```bash
npm run deploy
```

Deployed API uses remote D1 binding configured in `wrangler.jsonc`.

---

## 8) CI/CD model (recommended)

Typical pipeline:

1. Checkout
2. Install dependencies
3. Typecheck / tests
4. `npm run db:migrate:remote`
5. `npm run deploy`

CI authenticates with Cloudflare using secrets (API token + account id), not personal local login.

---

## 9) Troubleshooting

### `must provide --command or --file`

You likely ran query script without SQL argument.

Correct format:

```bash
npm run db:query:local -- "SELECT * FROM users;"
```

### Query shows success but no rows printed

The table is empty. Check count:

```bash
npm run db:query:local -- "SELECT COUNT(*) AS count FROM users;"
```

### Bash argument issue

Use a space after `--`:

✅ `npm run db:query:local -- "SELECT ..."`

❌ `npm run db:query:local --"SELECT ..."`
